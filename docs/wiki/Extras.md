# Extras

All of these live in **Sidewinder Welcome** (app menu).

## HUD
Shows FPS, CPU and GPU temps in every Steam game, fighter jet style.
- Press **HUD** to turn it on or off, then restart Steam
- In a game, **Right Shift + F12** hides or shows it

## Saves
Your game saves are backed up every day to **Game Save Backups** in your home folder.
- Press **SAVES** to open the backup app and restore one

## TV mode
Steam full screen, made for a controller. Great on a TV over HDMI.
- Press **TV MODE**
- To leave: Steam menu > Power > Exit Big Picture

## Battery care
Stops charging at 80% so the battery lasts more years. Best if the laptop is plugged in most of the time.
- Press **BATTERY CARE** to turn it on or off
- Turn it off the night before a trip to get a full charge

## Game mode
Full power for games. Turns on by itself when you plug in the charger, and back off on battery.

## Radar (the browser)
Sidewinder's own web browser. Blocks ads and trackers, and you can edit the shortcuts on its start page.
- Background tabs freeze while Game mode is on, so games get the power
- Firefox is also installed if a site doesn't work in Radar

## Proton
GE-Proton updates itself every week. In Steam, right click a game > Properties > Compatibility to pick it if a game won't start.
