# First boot

## Setup
The first time Sidewinder starts, a short setup asks for:
1. Your language and keyboard
2. Wi-Fi
3. Your name and a password. Pick one you'll remember, you'll type it to log in and for updates.

## The welcome app
After you log in, **Sidewinder Welcome** opens. It has a big button for everything:

| Button | What it does |
|---|---|
| UPDATE | Gets the newest version of everything |
| FIX PROBLEMS | Restarts sound, Wi-Fi and Bluetooth, checks your apps |
| GAME MODE | Full power for games |
| GO BACK | Undoes the last update |
| WIKI | Opens this wiki |
| TERMINAL | For advanced users |

It only opens by itself the first time. Find it again in the app menu (the Sidewinder logo, bottom left).

## Your game apps
Steam, Heroic and Lutris download by themselves in the background right after the first boot. It takes a few minutes, and the welcome app tells you when they're ready. Then see [[Playing games]].
