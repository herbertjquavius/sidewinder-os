# Troubleshooting

**Try this first for almost anything:** Welcome → **FIX PROBLEMS**, then restart.

| Problem | Fix |
|---|---|
| No sound | FIX PROBLEMS. Check the speaker icon near the clock is on the right output. |
| Wi-Fi or Bluetooth gone | FIX PROBLEMS. Check airplane mode is off. |
| Controller not working | See [[Controllers]]. |
| Game won't start | Steam: Properties → Compatibility → Proton Experimental. Check protondb.com. |
| Game runs slow | Plug in the charger, turn on GAME MODE, close browsers. See [[Performance]]. |
| Broke after an update | Welcome → GO BACK → RESTART NOW. |
| Won't start, black screen | See [[Updates and going back]], "It won't even start?". |
| Screen frozen | Wait 30 seconds. Then hold the power button 10 seconds and turn it back on. |
| Steam missing after first boot | Wait a few minutes, it's still downloading. Restart if it's been more than 30 minutes. |
| Forgot password | Ask whoever set up the computer. |

Still stuck? Report it on the project page with what you were doing and a photo of the screen.
