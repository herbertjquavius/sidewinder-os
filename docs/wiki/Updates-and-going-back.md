# Updates and going back

## Updates happen by themselves
Twice a day, Sidewinder checks for updates and downloads them quietly. They kick in **the next time you restart**. It never restarts on its own, so a game is never interrupted.

Want it now? Welcome → **UPDATE**, then **RESTART NOW** when you're done playing.

## Going back
Every update keeps the version before it. If an update breaks something:
- Welcome → **GO BACK** → **RESTART NOW**

Your games, saves and files are never touched, only the system itself changes.

## It won't even start?
1. Hold the power button 10 seconds to turn it off, then turn it on.
2. Tap **Esc** while it starts until a menu shows up. (After a failed start, the menu shows up by itself.)
3. Pick the **second line**, the previous version, and press Enter.
