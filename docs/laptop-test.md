# Laptop test checklist

Do this only with your brother's OK. Installing erases the whole laptop.

## Before
- [ ] Your brother says yes
- [ ] Back up everything he wants to keep: game saves, photos, files. Copy them to a USB drive or cloud, then open a few to make sure they copied
- [ ] Laptop plugged in to the charger
- [ ] A USB stick of 16 GB or more (it gets erased too)
- [ ] Download the ISO from the latest green "iso" run on GitHub (Actions tab, install-iso)
- [ ] Write it to the stick with Fedora Media Writer (on Bazzite: Discover, search "Fedora Media Writer", choose "Select .iso file")

## Install
- [ ] Plug in the stick, restart, tap the boot menu key while it starts (often F12, F11 or Esc) and pick the USB
- [ ] Pick the laptop's drive (not the USB), choose to erase it, then Begin Installation
- [ ] After the restart a blue screen appears: press a key, Enroll MOK, Continue, Yes, type `sidewinder`, Reboot
- [ ] Setup screens: name, password, Wi-Fi

## Check
- [ ] Login screen and desktop look right
- [ ] Wi-Fi, sound, brightness keys, sleep and wake (close the lid, open it)
- [ ] Welcome app opens; apps finish installing (Steam, Discord and the rest)
- [ ] A game runs on the NVIDIA card (turn on HUD in the welcome app, it shows the GPU)
- [ ] Radar opens YouTube and plays video; the Shorts button works
- [ ] Copy the backed up saves back

If anything fails, write down what you saw (a phone photo is perfect) and send it to me.
