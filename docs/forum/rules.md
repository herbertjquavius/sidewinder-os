# Forum rules

Short and simple:

1. **Be kind.** Everyone was new once. No insults, no harassment, no hate.
2. **Stay on topic.** Sidewinder, Linux gaming, and the games themselves.
3. **No piracy, cheats or hacks.** Don't ask for them, don't share them.
4. **One problem per post.** It's easier to help, and easier to find later.
5. **Use the forms** for bug reports and game reports.
6. **Keep personal info private.** No passwords, addresses or phone numbers, yours or anyone else's.
7. **Mark answers.** If a reply fixed your problem in Help and Support, mark it as the answer.

Posts that break these rules get removed. Repeat problems get you blocked.
